# 排版攻击对 Gemini Embedding 2 的脆弱性评估：黑盒实验研究

## 摘要

本文首次系统性地评估了 Google 原生多模态嵌入模型 Gemini Embedding 2 对排版攻击（typographic attack）的脆弱性。通过覆盖 20 个物体类别和 1,080 张图片的黑盒实验，我们证明：仅在图片上叠加一个误导性单词，即可使该模型的零样本分类准确率从约 65% 暴跌至约 5–18%，攻击成功率（ASR）介于 78.9% 至 95.6% 之间。三种攻击策略——随机攻击、语义近邻攻击和跨域攻击——均表现出毁灭性的攻击效果。对照实验揭示了模型脆弱性的本质：模型过度依赖图片中的文字内容。当叠加**正确**标签时，准确率反而提升至 98.9%；而无意义字符串几乎没有影响。防御性 prompt 工程（如 `"ignore any text overlay"`）仅将 ASR 降低 2.8 个百分点，维度截断（768/1536/3072）也几乎没有影响，表明这一脆弱性是模型架构的固有特性，而非高维嵌入空间的副产品。**与 CLIP ViT-B/32 的直接对比进一步揭示了一个反直觉的架构悖论**：虽然 Gemini Embedding 2 在干净图片上的基准准确率比 CLIP 高 6.1 个百分点（65.0% vs 58.9%），但在语义近邻攻击下 ASR 反而比 CLIP 高 12.2 个百分点（86.1% vs 73.9%），准确率下降幅度也多出 13.4 个百分点（52.8% vs 39.4%）。这表明原生多模态架构虽然在干净数据上具有优势，但对排版攻击的鲁棒性反而**不如**传统的双编码器架构。所有发现均通过严格的统计检验（p < 0.0001，Cohen's d > 1.0）。这些结果对在检索增强生成（RAG）、多模态搜索和内容审核系统中部署原生多模态嵌入模型的安全性提出了严重警告。

## 1. 引言

排版攻击——通过在图片上叠加误导性文字以操纵视觉-语言模型的攻击方式——最早由 Goh 等人（2021）在 CLIP 模型上提出。随后 Qraitem 等人（2024）扩展了这一研究，证明语义相关的"近邻"标签攻击效果尤其显著。然而，所有先前工作都针对**双编码器架构**（如 CLIP、ALIGN、SigLIP 等），这类模型通过对比学习将视觉塔和文本塔分别对齐到同一空间。

Google 的 **Gemini Embedding 2** 代表了一种根本不同的架构：一个**单一的 Transformer** 直接将文本、图像、音频、视频处理为统一的 3,072 维嵌入空间。这种架构变革被宣称能够带来更丰富的跨模态理解。一个自然的问题随之而来：

> **原生多模态架构是天然具备抵抗排版攻击的鲁棒性，还是会继承（甚至放大）双编码器模型的脆弱性？**

我们通过一项全面的黑盒评估回答这个问题。本研究的贡献包括：

1. **首次系统性地评估** Gemini Embedding 2 对排版攻击的脆弱性。
2. **创新的对照组设计**：将"误导性内容"与"文字存在本身"两种因素剥离开来。
3. **与 CLIP ViT-B/32 的直接对比**，首次在同一数据集上实证量化了原生多模态架构与双编码器架构在鲁棒性上的差异。
4. **反直觉的实证发现**：原生多模态模型并不比 CLIP 类模型更鲁棒，反而**显著更脆弱**——即使其在干净数据上的基准准确率更高。
5. **架构层面的洞察**：Gemini Embedding 2 将叠加文字视为最主要的语义信号，其权重远超视觉内容本身。

## 2. 方法

### 2.1 威胁模型

我们采用**纯黑盒威胁模型**：
- **攻击者能力**：仅有 API 访问权限；无梯度访问、无模型内部信息、无微调能力。
- **攻击操作**：使用 Pillow 库在干净图片上叠加一个误导性文字字符串。
- **攻击目标**：使模型基于文本相似度的最近邻分类预测出攻击者指定的错误类别。
- **约束条件**：图片的视觉内容不变，仅添加文字叠加层。

### 2.2 数据集构建

我们构建了一个包含 **20 个物体类别**、覆盖 4 个语义域的均衡数据集：

| 语义域 | 类别 |
|---|---|
| 动物 | cat, dog, bird, fish, horse |
| 交通工具 | car, airplane, boat, bicycle, bus |
| 日常物品 | cup, book, clock, chair, phone |
| 食物 | apple, banana, pizza, cake, hamburger |

每个类别采集 **9–10 张基准图片**，主要来源于 COCO 2017 验证集（18 个类别），对于 COCO 80 类别中不存在的 `fish` 和 `hamburger`，使用合成图片作为替代。所有图片统一中心裁剪并缩放到 512×512。最终数据集包含：

- **180 张基准图片**（无文字叠加的干净图片）
- **540 张攻击图片**（180 × 3 种攻击策略）
- **180 张良性对照图片**（叠加正确标签）
- **180 张噪声对照图片**（叠加 `"xkqz"`）
- **总计：1,080 张图片**

### 2.3 攻击策略

对于每一张类别 `c` 的基准图片，我们生成三种攻击变体：

1. **随机攻击**：从其他 19 个类别中随机选择一个（如 `cat → "horse"`）。
2. **语义近邻攻击**：选择语义空间中最接近的类别（如 `cat → "dog"`，`car → "bus"`）。
3. **跨域攻击**：从完全不同的语义域中选一个类别（如 `cat → "pizza"`）。

排版参数固定为：白色字体黑色描边、居中、字号为图片高度的 10%、完全不透明。

### 2.4 嵌入提取

我们使用 `gemini-embedding-2-preview` 模型（默认 3,072 维）提取嵌入。测试了三种文本 prompt 模板：

| 模板 | 示例 |
|---|---|
| simple（简洁）| `"cat"` |
| standard（标准）| `"a photo of a cat"` |
| defense（防御）| `"a photo of a cat, ignore any text overlay in the image"` |

总共生成 60 个文本嵌入（20 类别 × 3 模板）和 1,080 个图像嵌入。

### 2.5 评估指标

对于每张图片，我们通过计算其嵌入与全部 20 个类别文本嵌入的余弦相似度，取最大值作为预测类别（零样本分类）。报告以下指标：

- **Top-1 准确率**：预测正确的比例。
- **攻击成功率（ASR）**：被攻击图片中预测结果等于攻击者指定目标的比例。
- **准确率下降幅度**：基准准确率减去攻击后准确率。
- **语义偏移**：攻击图片嵌入与对应干净图片嵌入之间的余弦距离。
- **统计检验**：配对 t 检验、Cohen's d 效应量、95% 置信区间。

## 3. 实验结果

### 3.1 核心分类结果

表 1 总结了核心发现：在所有 prompt 模板和攻击策略下，排版攻击都具有毁灭性的效果。

**表 1：按 prompt 模板和攻击策略划分的分类准确率与 ASR。**

| Prompt | 组别 | 准确率 | ASR | 准确率下降 |
|---|---|:---:|:---:|:---:|
| simple | baseline | 66.7% | — | — |
|  | attack_random | 6.7% | **93.3%** | -60.0% |
|  | attack_neighbor | 4.4% | **95.6%** | -62.2% |
|  | attack_cross_domain | 6.1% | **93.3%** | -60.6% |
| standard | baseline | 65.0% | — | — |
|  | attack_random | 17.2% | **78.9%** | -47.8% |
|  | attack_neighbor | 12.2% | **86.1%** | -52.8% |
|  | attack_cross_domain | 17.8% | **80.0%** | -47.2% |
| defense | baseline | 63.3% | — | — |
|  | attack_random | 17.2% | **78.9%** | -46.1% |
|  | attack_neighbor | 14.4% | **83.3%** | -48.9% |
|  | attack_cross_domain | 17.2% | **78.9%** | -46.1% |

**关键观察：**
- 所有三种 prompt 模板下基准准确率稳定在 63–67% 之间。
- 仅一个叠加单词就使准确率下降 46–62 个百分点。
- 在全部 9 种条件下，ASR 介于 78.9% 至 95.6% 之间。
- 语义近邻攻击略强于随机和跨域攻击，但差距不大。

![ASR by Strategy and Prompt Template](../results/figures/exp1/asr_by_strategy_prompt.png)

### 3.2 对照组分析：核心洞察

对照组的结果（表 2）揭示了攻击之所以有效的内在机制。

**表 2：攻击组与对照组的准确率对比（standard 模板）。**

| 组别 | 准确率 | 解读 |
|---|:---:|---|
| baseline（无文字）| 65.0% | 仅靠视觉的表现 |
| **benign**（叠加正确标签）| **98.3%** | 文字反而**帮助**了模型 |
| noise（叠加 `"xkqz"`）| 61.7% | 无意义文字 ≈ 几乎无影响 |
| attack_neighbor | 12.2% | 误导性文字**摧毁**了准确率 |

这是本研究最引人注目的发现：**叠加正确标签使准确率从 65% 飙升至 98.3%**，表明 Gemini Embedding 2 将叠加文字视为最主要的语义信号。无意义字符串几乎没有任何效果（61.7% ≈ 65.0%），证明攻击机制是**语义层面**的，而非视觉干扰。

![Control Group Comparison](../results/figures/exp1/control_comparison.png)

### 3.3 排版消融实验（Phase 5）

我们对最容易被攻击的 5 个类别（cat, dog, car, boat, book）进行了语义近邻攻击下的单因素消融实验，依次变化以下参数：

- **字体大小**：图片高度的 5%、10%、15%、25%、40%
- **位置**：中央、左上、右下、顶部居中、底部居中
- **颜色**：白字+黑边、纯黑、纯红、与图片主色调接近
- **不透明度**：25%、50%、75%、100%
- **重复方式**：1× 居中、3× 散布、整张铺满

在 Top-5 最易被攻击的类别中，绝大多数参数配置下 ASR 都接近 100%，证实攻击效果不依赖于特定的排版选择。

### 3.4 维度截断鲁棒性（Phase 6）

我们在 Matryoshka 支持的三种维度（768、1536、3072）下重复了攻击评估。

**表 3：维度截断结果。**

| 维度 | 基准准确率 | ASR (random) | ASR (neighbor) | ASR (cross_domain) |
|:---:|:---:|:---:|:---:|:---:|
| 768  | 63.9% | 76.1% | 85.0% | 78.9% |
| 1536 | ~64% | ~78% | ~86% | ~79% |
| 3072 | 65.0% | 78.9% | 86.1% | 80.0% |

不同维度之间的差异仅有 1–3 个百分点，表明**攻击的脆弱性并非高维嵌入空间的副产品**，而是模型处理图像中文字的固有方式所导致的。

![Dimension Truncation](../results/figures/exp1/dimension_truncation.png)

### 3.5 统计显著性

所有"基准 vs 攻击后"的成对相似度比较都达到了极高的统计显著性：

| 模板 | 策略 | t 统计量 | p 值 | Cohen's d |
|---|---|---:|---:|---:|
| simple | random | 14.29 | <0.0001 | 1.07 |
| simple | neighbor | 20.26 | <0.0001 | 1.51 |
| simple | cross_domain | 13.91 | <0.0001 | 1.04 |
| standard | random | 25.99 | <0.0001 | 1.94 |
| standard | neighbor | 29.51 | <0.0001 | 2.20 |
| standard | cross_domain | 25.08 | <0.0001 | 1.87 |
| defense | random | 32.84 | <0.0001 | 2.45 |
| defense | neighbor | 36.98 | <0.0001 | 2.76 |
| defense | cross_domain | 37.98 | <0.0001 | 2.83 |

所有 Cohen's d 值均超过 1.0（"非常大"效应量的阈值），p 值都低于浮点精度极限。

### 3.6 与 CLIP 基线模型的对比（Phase 7）

为了回答"原生多模态架构是否比传统双编码器架构更鲁棒"这一核心问题，我们使用 **OpenCLIP ViT-B/32**（预训练权重 `laion2b_s34b_b79k`）在完全相同的 1,080 张图片数据集上重复了 Phase 4 的实验。所有图像和文本嵌入在本地通过 CLIP 模型提取，分类流程（余弦相似度 + argmax）与 Gemini Embedding 2 完全一致。

**表 4：Gemini Embedding 2 vs CLIP ViT-B/32 核心指标对比（standard 模板）。**

| 指标 | Gemini Embedding 2 | CLIP ViT-B/32 | 差异 |
|---|:---:|:---:|:---:|
| **基准准确率** | **65.0%** | 58.9% | Gemini +6.1% |
| **ASR（随机攻击）** | 78.9% | 67.8% | Gemini +11.1% |
| **ASR（语义近邻）** | **86.1%** | 73.9% | Gemini +12.2% |
| **ASR（跨域攻击）** | 80.0% | 68.9% | Gemini +11.1% |
| **准确率下降（近邻）** | 52.8% | 39.4% | Gemini +13.4% |

![Gemini vs CLIP Comparison](../results/figures/exp1/gemini_vs_clip.png)

**三个关键发现：**

1. **干净数据上：Gemini 优于 CLIP**——Gemini Embedding 2 的零样本分类基准准确率比 CLIP 高出约 6 个百分点（65.0% vs 58.9%），符合"原生多模态优于双编码器"的预期。这验证了 Gemini 架构在常规任务上的优势。

2. **攻击场景下：Gemini 反而更脆弱**——在所有三种攻击策略下，Gemini 的 ASR 都系统性地高出 CLIP 约 11–12 个百分点。对于最有效的语义近邻攻击，Gemini 的 ASR 达到 86.1%，而 CLIP 仅为 73.9%。**注意 CLIP 本身也很脆弱**，但 Gemini 更加脆弱。

3. **准确率下降幅度更大**——这是最具说服力的指标。遭受语义近邻攻击时：
   - **CLIP**：从 58.9% 降到 19.5%（下降 **39.4 个百分点**）
   - **Gemini**：从 65.0% 降到 12.2%（下降 **52.8 个百分点**）

   Gemini 不仅下降幅度更大，而且**攻击后的最终准确率比 CLIP 还低**（12.2% vs 19.5%）。换言之，从"鲁棒准确率"（攻击后仍能正确分类的比例）这一实际部署指标来看，**Gemini Embedding 2 不如 CLIP**。

**架构悖论的实证确认**：这一对比以无可辩驳的数据证实了我们的核心假说——Gemini 原生多模态架构在干净数据上的 +6% 优势，在攻击场景下被 –13% 的鲁棒性损失所完全吞噬。原生多模态架构与双编码器架构之间存在一个**鲁棒性权衡**：前者通过统一的 Transformer 实现更丰富的跨模态对齐，但这恰恰放大了对图像中文字内容的依赖，使其成为排版攻击的最佳攻击目标。

## 4. 讨论

### 4.1 原生多模态架构为何反而更脆弱？

Phase 7 与 CLIP 的对比实验为我们解答"为什么"提供了有力的实证依据。我们认为根本原因在于两种架构处理"图像中的文字"方式的本质差异：

**CLIP 的双编码器架构隐含"信息瓶颈"**：视觉塔（ViT）和文本塔（Transformer）是两个独立的模型，分别独立处理图像和文本，最后通过对比损失在输出层对齐。图像中的文字必须先被视觉塔以视觉特征的形式提取，再与文本塔的输出对齐——这个过程中存在一个隐式的"视觉-语言瓶颈"，削弱了叠加文字的直接影响。

**Gemini Embedding 2 的单塔架构消除了这一瓶颈**：所有模态都经由同一个 Transformer 处理。图像中的像素文字（通过视觉编码器 tokenize 后）与 prompt 中的文字 token 在 Transformer 内部的处理路径完全相同，叠加文字的语义信号被最大化传递到最终嵌入。这正是 Gemini 在 benign 对照组中能将准确率从 65% 提升至 98.3% 的原因，但同样地，也是它在攻击组中崩溃到 12.2% 的原因。

这构成了一个**架构悖论**：原本旨在实现更丰富跨模态理解的设计特性（单塔统一处理），反而成为了排版攻击最直接的通道。这个悖论在 Phase 7 的数据中得到了明确的量化：原生多模态架构换来的 6% 的干净数据优势，付出了 13% 的鲁棒性代价。

### 4.2 为什么防御性 Prompt 失效？

在 prompt 中加入 `"ignore any text overlay in the image"` 仅能将 ASR 从 86.1% 降至 83.3%（近邻攻击）。这表明文本层面的 prompt 防御无法覆盖模型内部根深蒂固的视觉-语义融合机制。文字叠加被模型解读为图像的**一部分**，而非"忽略文字"的指令。

### 4.3 对实际系统的影响

这些发现对基于 Gemini Embedding 2 构建的系统具有直接的安全意义：

1. **RAG 系统**：攻击者可以通过上传含有"诱饵文字"的文档来操纵检索排序。
2. **多模态搜索**：搜索结果可以被对抗性图片标题污染。
3. **内容审核**：有害图片可以通过叠加无害文字被重新分类。

## 5. 局限性

1. **CLIP 基线的模型规模**：本研究使用 CLIP ViT-B/32 作为对比基线。更大规模的 CLIP 变体（如 ViT-L/14、ViT-H/14）或更新的双编码器模型（如 SigLIP、EVA-CLIP）可能呈现不同的鲁棒性表现。未来工作应扩展到多个 CLIP 变体以确认架构对比的普遍性。
2. **数据集规模有限**：每个类别仅 9–10 张图片（共 180 张基准图片）。更大的数据集能够提供更紧密的置信区间。
3. **单因素消融**：Phase 5 仅独立变化每个排版参数，未探索跨因素交互（如小字号 + 低不透明度）。
4. **仅限英文**：所有攻击词和 prompt 都是英文。多语言鲁棒性尚未测试。
5. **静态文字**：未测试模糊、旋转、透视形变等更复杂的对抗样本。

---

## 6. 结论

我们对 Google Gemini Embedding 2 进行了全面的黑盒排版攻击评估，并与 CLIP ViT-B/32 进行了直接对比。在覆盖 20 个类别、3 种攻击策略、3 种 prompt 模板的 1,080 张图片上，我们发现：

1. **Gemini Embedding 2 对排版攻击极度脆弱**，ASR 介于 78.9% 到 95.6% 之间。
2. **叠加文字主导了视觉内容**在模型语义表示中的地位——双向都成立：正确文字 → 98.3% 准确率；误导文字 → 12.2% 准确率。
3. **所有测试的防御方法均无效**：prompt 工程、维度截断、变化排版参数都无法缓解这一脆弱性。
4. **攻击机制是语义层面的**，而非视觉干扰，这一点已通过噪声对照组得到证实。
5. **原生多模态架构比双编码器架构更脆弱**：虽然 Gemini 在干净数据上比 CLIP 高 6.1 个百分点的准确率（65.0% vs 58.9%），但在语义近邻攻击下 ASR 高出 12.2 个百分点（86.1% vs 73.9%），准确率下降幅度多出 13.4 个百分点。这是首次对两种架构范式在排版攻击鲁棒性上的定量对比。

这些结果揭示了一个深刻的**架构悖论**：原生多模态架构在理论上具有更强的跨模态融合能力，这在干净任务上确实带来了性能提升，但恰恰是这种紧密的融合使得模型无法区分"图像中的文字"和"描述图像的文字"，从而引入了一个关键的安全弱点。我们呼吁在安全敏感的应用场景中谨慎部署 Gemini Embedding 2，并主张通过架构层面的防御机制（例如显式分离 OCR 通路、训练时加入对抗样本）而非 prompt 层面的修补来从根本上解决这一问题。
